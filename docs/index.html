What it does

📊 Live official data

Eurostat Comext, UN Comtrade and World Bank APIs; no estimates or invented numbers.

📈 Supply concentration

Herfindahl-Hirschman Index shows dependency on dominant suppliers such as China.

🎯 Transparent scoring

A 0-10 attractiveness score from size, growth, openness, institutions and logistics.

🧭 IB frameworks

PESTEL, CAGE distance, risk matrix and OLI-based entry-mode logic, built into code.

🇪🇺 EU-27 ranking

Ranks all member states to pick the best first markets.

🤖 Optional AI agent

A Claude tool-use agent can add live web research on tariffs and regulation.

How it works

Describe the case

Product (HS6 code), target market (EU, a member state or China), home country and company size.

Pull live data

Trade flows, supplier shares, macro, logistics and governance indicators.

Analyse

Market size and growth, HHI, attractiveness score, CAGE distance, EU-27 ranking.

Decide

Verdict, PESTEL, regulation checklist, risk matrix, entry mode and a 90-day plan.

Run the interactive app (dashboard, custom reports, EU-27 ranking) locally with streamlit run app.py; see the quick start.
